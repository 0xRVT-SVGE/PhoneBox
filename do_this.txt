and what about grafana and prometheus

For an embedded-oriented setup, running Prometheus and Grafana on Windows directly is not a good fit. You have two realistic options:

Option 1 — Run them in WSL (recommended compromise)
This keeps things lightweight enough while staying close to Linux (your likely target).

Prometheus
# download
wget https://github.com/prometheus/prometheus/releases/latest/download/prometheus-*.linux-amd64.tar.gz

# extract
tar xvf prometheus-*.tar.gz
cd prometheus-*

# run
./prometheus --config.file=prometheus.yml
Access:

http://localhost:9090
Grafana
sudo apt install -y software-properties-common
sudo add-apt-repository "deb https://packages.grafana.com/oss/deb stable main"
wget -q -O - https://packages.grafana.com/gpg.key | sudo apt-key add -
sudo apt update
sudo apt install grafana -y
Start:

sudo service grafana-server start
Access:

http://localhost:3000
Option 2 — Bare binaries (even lighter, no package manager)
Prometheus
Download and run directly:

./prometheus --config.file=prometheus.yml
Grafana
Download .tar.gz, extract, then:

./bin/grafana-server
