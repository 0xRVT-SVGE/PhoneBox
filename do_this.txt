7. Production: stable USB cameras
bash# First run — interactive setup with preview windows:
python -m back_end.camera_manager --setup

# Subsequent runs — load persisted config automatically.
# Force reconfigure after changing USB ports:
python -m back_end.camera_manager --setup
The persisted camera_config.json (stored next to camera_manager.py):
json{
  "bottom_cam": {
    "index": 1,
    "name": "HD USB Camera",

  },
  "top_cam": {
    "index": 2,
    "name": "Logitech C270",

    "path": "/dev/video2"
  },
  "front_cam": {
    "index": 0,
    "name": "Integrated Camera",
    "uid": "usb-0000_0001_00-video-index0",

  },

}
If a camera is unplugged and re-plugged on a different port, Linux may
assign it a new /dev/videoN index.  The UID (symlink name from
/dev/v4l/by-id) stays the same, so CameraManager.resolve() will
find it automatically.  Call cam_mgr.resolve() after any hot-plug
event to refresh the mapping without restarting.
